## 💡 新手学习建议

1. **动手敲**：不要光看，亲手敲一遍代码
2. **改一改**：试着修改参数，看看会发生什么
3. **加功能**：在基础版本上加自己想加的功能
4. **查文档**：遇到不懂的就查官方文档
5. **多练习**：编程是练出来的，不是看出来的
